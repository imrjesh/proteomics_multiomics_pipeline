# Installation & Usage

## Tested platform
- macOS (Apple M2 Pro, osx-64 via Rosetta) and Linux
- conda/mamba (Miniforge)

## 1. Environment

`environment.yml`:

```yaml
name: proteomics-downstream
channels: [conda-forge, bioconda]
dependencies:
  - r-base
  - r-yaml
  - r-dplyr
  - r-tibble
  - r-tidyr
  - r-ggplot2
  - r-circlize
  - r-matrixstats
  - bioconductor-limma
  - bioconductor-complexheatmap
  - bioconductor-fgsea
  - bioconductor-impute
  - bioconductor-sva
  - bioconductor-gsva
  - bioconductor-clusterprofiler
  - bioconductor-org.hs.eg.db
  - bioconductor-org.mm.eg.db
  - r-msigdbr
```

```bash
# Apple Silicon
CONDA_SUBDIR=osx-64 mamba env create -f environment.yml
conda activate proteomics-downstream
conda config --env --set subdir osx-64

# Intel / Linux
mamba env create -f environment.yml
conda activate proteomics-downstream
```

## 2. Data

Toy data: generated by `make_toy_proteomics.R` (no download needed).

CPTAC LUAD: download `.cct` files from
https://linkedomics.org/data_download/CPTAC-LUAD/ and place in the project root.
The expected filenames are referenced in `config/config_cptac_luad.yaml`.

## 3. Run

```bash
# Toy
Rscript make_toy_proteomics.R
Rscript R/proteomics_downstream_pipeline.R config/config_toy.yaml

# CPTAC
Rscript prepare_cptac.R
Rscript R/proteomics_downstream_pipeline.R config/config_cptac_luad.yaml
Rscript R/proteomics_secondary_analysis.R  config/config_cptac_luad.yaml
Rscript R/proteomics_multiomics.R          config/config_cptac_luad.yaml
```

## 4. Outputs

Written under the config's `outdir`:
- `qc/`, `de/<contrast>/` — primary pipeline
- `secondary/` — correlation, clustering, ssGSEA, modules
- `multiomics/` — mRNA-protein, CNV-protein, phosphosite/kinase

## Known gotchas
- `there is no package called 'limma'` → activate the conda env.
- Apple Silicon solve fails → use `CONDA_SUBDIR=osx-64`.
- Kinase activity empty → provide a kinase-substrate GMT (`kinase_gmt`) or use decoupleR.
- Enrichment empty on toy data → expected (random signal); real data populates it.
